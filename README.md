# Nuna 个人画像交互 Demo

以长期用户为视角的手机端 UI/UX 原型。全部内容均为示例，未连接真实吊坠、麦克风或用户数据。

## 下载与使用

1. 在本仓库选择 **Code → Download ZIP**。
2. 解压后，用 Chrome、Edge 或 Safari 打开 `demo/index.html`。
3. 无需安装依赖或联网。编辑与确认结果保存在当前浏览器本地，可通过「画像设置 → 重置示例」恢复。

也可以打开 `demo/index.html` 的 GitHub 文件页面，通过 **Download raw file** 下载单文件。

## 功能

- 画像概览与五类内容入口
- 性格特质、原文依据与关联情绪时段
- 长远目标编辑与本地保存
- 一句话描述的选择、确认及历史
- 每周挑战性洞察的方向选择、阅读与删除
- 人格探索示例问答（不生成正式人格类型）

## 分享

分享仓库链接即可让有访问权限的人下载。仓库文件页展示源码；在线交互体验需要另行配置静态网站托管。

每次 Demo 更新通过 Git 提交保留版本，旧版本可从提交历史中获取。
